ckeaMaterial Icon Theme subset
==========================

Source: https://github.com/material-extensions/vscode-material-icon-theme
License: MIT, preserved in LICENSE-Material-Icon-Theme.txt

This directory vendors a compact SVG subset for JVN project/file explorer UI
and related project-preview trees. The full upstream icon pack is not bundled;
only the icons mapped by com.jvn.editor.ui.ProjectFileIcons are included.
