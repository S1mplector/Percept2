# Sidebar — Help Center

In-app documentation browser that discovers, indexes, and previews Markdown documentation files from the workspace and project.

Source: `editor/src/main/java/com/jvn/editor/ui/HelpCenterView.java`

---

## Overview

The Help Center provides immediate access to workspace and project documentation without leaving the editor. It indexes Markdown across the repo and project roots, organizes it into a progressive guide tree, and renders the selected document inline.

- **Default side:** Right
- **Tab name:** Help
- **Shortcut:** Press **F1** from anywhere in the editor to jump to the Help tab

## Guide Tree

A sectioned `TreeView` showing all discovered Markdown files in a progressive order:
- **Start Here** — index, beginner routes, and orientation pages
- **Visual Novel Authoring / Gameplay And JES / Animation And Timelines** — the main authoring paths
- **Menus And UI Layout / Editor And Tools / Runtime And Project Setup** — production systems
- **Architecture And Internals / Reference And Generated Docs** — lower-level and generated material
- **Current Project Docs** — project-local Markdown when a game project is open

Each leaf shows:
- **Title** — extracted from the first `# Heading` in the file (within the first 100 lines)
- **Relative path** — path relative to the source root
- **Summary** — first readable paragraph extracted from the document
- **Source label** — `Workspace` or `Project`

## Document Indexing

### Scan Sources

The Help Center scans:

1. **Workspace root** — repo-wide docs, module `README.md` files, and top-level Markdown like `README.md`
2. **Project root** — the currently opened project, including project-local docs and Markdown files

### Scan Process

1. Recursively walk the workspace and project roots
2. Collect all `.md` files outside skipped folders like `build/`, `.git/`, and `.jvn-gradle-user-home/`
3. Extract the title from the first `# Heading` line (within the first 100 lines)
4. Extract a short summary from the first readable paragraph
5. Deduplicate by canonical path
6. Classify docs into guide sections for progressive browsing
7. Sort docs within each section using onboarding-first ranking
8. Update the stats label with visible/total counts

### Title Extraction

The scanner reads up to `TITLE_SCAN_LINE_LIMIT` (100) lines from each Markdown file, looking for a line starting with `# `. The first match becomes the document's title. If no heading is found, the filename is used as the title.

## Refresh

The **Refresh** button triggers a full re-index:
1. Clears the current index
2. Rescans both workspace and project roots
3. Reapplies the current filter
4. Restores the current selection when possible
5. Selects the first visible document if nothing is selected
5. Updates quick access button states

Refresh is also called automatically when `setWorkspaceRoot()` or `setProjectRoot()` is called.

| Callback | Description |

| `setWorkspaceRoot(File)` | Sets the JVN workspace root for framework doc discovery |
| `setProjectRoot(File)` | Sets the game project root for project-specific doc discovery |

## F1 Shortcut

The editor registers a global F1 shortcut that:
1. Ensures the Help tab exists in the sidebar
2. Selects the Help tab
3. Focuses the Help Center panel

This provides instant access to documentation from anywhere in the editor.
